# Audio add-on report

## What existed before this task (summary)
1. `src/lib/ivr.js` is a pure voice-menu state machine (startCall, nodeClips, afterPlay, onSilence, pressKey, numberClips) driven by `src/data/ivr/flow.json`; it reuses `makeContext` from `src/lib/ussd.js`.
2. `flow.json` nodes: greet, welcome, alert_call, main (one clip `menu_main`), plant, plant_detail, sell, sell_result, alerts, produce…, report…, unregistered, lead_record, goodbye. Keys 9 repeat / 0 back / * main.
3. `src/data/ivr/clips.json` (117 clips, fields id, en_script, starter, langs_done) was generated by a one-off scratch script, not from a CSV.
4. `src/lib/render.js` `render(signal, 'voice', lang, {kind, crop, reason})` returns clip IDs (crop + verdict + reason).
5. `src/lib/voicePlayer.js` plays clips: tries `audio/{lang}/{id}.mp3|.ogg`, then English, then speechSynthesis (rate 0.95); it LOGS missing clips to localStorage and Admin → Demo → Voice clips lists them.
6. `src/components/farmer/useVoiceCall.js` runs calls (ring, answer, DTMF interrupt, 8 s silence replay, goodbye hang-up, recording) using voicePlayer; `BasicPhone.jsx` draws the call screens.
7. `src/components/farmer/FarmerSim.jsx` = side panel (holder, quick dial, language, subtitles toggle) + subtitles panel under the phone.
8. `src/components/shared/AudioButton.jsx` (kafo 🔊) only speaks English text with speechSynthesis; it does not use clips.
9. Spec lives in `spec/spec.md` (not docs/spec.md); `docs/` is local reference material. `docs/clips.csv` (105 clips, columns clip_id…note) is the user's new master list.
10. Recordings present: 10 Mandinka `.ogg` files in `public/audio/mnk/` (menu_9_repeat and menu_back not recorded yet); no name clips.
